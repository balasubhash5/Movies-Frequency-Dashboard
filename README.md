# Movies-Frequency-Dashboard
Developed an interactive Movies Analysis Dashboard using Power BI to analyze movie genres, revenue, runtime, popularity trends, and language-wise ratings. Used interactive visualizations to identify popular genres, top-revenue movies, and yearly trends to support data-driven insights into movie performance.
📌 Project Overview

The Movies Analysis Dashboard is an interactive business intelligence project developed using Microsoft Power BI to explore movie genres, revenue, runtime, popularity, and language-wise ratings. It helps analyze movie performance and discover trends across different years and genres.

🎯 Project Objectives

Analyze the distribution of movies across genres.

Identify movies with the highest revenue.

Explore average movie runtime by year.

Track popularity trends over time.

Compare average revenue across movie genres.

Analyze movie ratings across different original languages.

🛠️ Tools & Technologies

Power BI – Dashboard development and visualization

Power Query – Data cleaning and transformation

DAX – Measures and calculations

Data Visualization – Bar charts, line charts, scatter plots, and tables

📊 Dashboard Features

1. Movie Count by Genre

Displays the number of movies in each genre to identify the most frequently represented categories.

2. Revenue by Movie Title

Compares movie revenue to highlight top-performing titles.

3. Average Runtime by Year

Visualizes changes in average movie runtime over time.

4. Average Popularity by Year

Tracks yearly popularity patterns and highlights notable fluctuations.

5. Language-Wise Genre Ratings

Presents a matrix comparing movie ratings across original languages and genres.

6. Average Revenue by Genre

Uses a scatter plot to compare average revenue across genres and identify differences in financial performance.

💡 Key Insights

Drama, Comedy, and Action are among the most frequently represented genres in the dashboard.

The revenue chart highlights several movies with high reported revenue.

Average runtime varies across years, with notable fluctuations in the displayed historical data.

Movie popularity changes over time, including a prominent spike in recent years.

Average revenue differs across genres, indicating variation in financial performance.

📈 Business Benefits

Supports movie performance analysis.

Helps identify frequently represented genres and high-revenue titles.

Reveals trends in runtime and popularity.

Enables comparisons of revenue across genres.

Demonstrates data analysis and visualization skills.
